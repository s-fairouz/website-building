1
Commande validée sur Shopify
Shopify
Le client finalise sa commande. Shopify collecte toutes les données nécessaires au certificat.
Données collectées
Prénom enfant, animal, variante, tissu, broderie, artisane
N° de commande généré
KW-2025-00142
2
Webhook déclenché automatiquement
Webhook POST
Shopify envoie un webhook orders/paid vers ton serveur dès que le paiement est confirmé. Aucune action manuelle.
POST https://api.kwaii.fr/webhook/order-paid
{
  "order_id": "KW-2025-00142",
  "customer": { "first_name": "Léa" },
  "line_items": [{ "name": "Buni · Fille · Sans bras" }],
  "note_attributes": [
    { "name": "broderie", "value": "Léa" },
    { "name": "artisan_id", "value": "isabelle" }
  ]
}
3
Génération du QR code unique
Backend
Le backend génère un identifiant unique et crée le QR code pointant vers la page souvenir de l'adoption.
URL encodée dans le QR
kwaii.fr/adoption/KW-2025-00142
Librairie recommandée
qrcode (npm) ou qrcode.js
Format PNG 300×300px

5
Stockage et création de la page souvenir
Base de données
Le PDF est stocké en cloud (S3 ou Cloudinary). La page souvenir est créée en base de données et devient accessible via le QR code.
Stockage PDF
AWS S3 · Cloudinary · Supabase Storage
Page souvenir créée
/adoption/KW-2025-00142
Profil artisane + galerie photos
6
Email de confirmation envoyé
Klaviyo / Mailchimp
Un email automatique est envoyé à la famille avec le lien de téléchargement du certificat PDF et la page souvenir.
Objet : "Le certificat d'adoption de Léa est prêt ! ✨"
Contenu : photo du certificat en aperçu · lien de téléchargement PDF · lien page souvenir · message de l'artisane
7
Certificat imprimé dans le coffret
Livraison physique
L'artisane imprime le PDF sur papier vergé A5 et l'insère dans le coffret Kwaii avec le doudou. Le QR code sur le certificat renvoie vers la page souvenir en ligne.
